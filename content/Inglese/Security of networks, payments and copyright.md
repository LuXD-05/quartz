### Network security

Network security consists of policies and practices to prevent (and monitor) unauthorized access to a network and its resources. It includes:

- Identification: identifying every user by username / user ID,
- Authentication: every user has to prove his identity by digiting a password. The password can be based on:
	- *Something the user knows*: like a string or pin-based password,
	- *Something the user has*: like identity documents or RFID identification cards,
	- *Something the user is*: like biometrics, such as fingerprints or eye scan.
- Authorization: defining the permissions for each user (what the users can do, like read-only, edit permission...).

###### Secure server

Since any stop could reveal personal info when transferred in internet, it's important to use a secure server because it encrypt info and make it readable only by the receiver.
