### Autenticazione
Hint: HTTP Basic (3 step)
::
Una tecnica di auth è l’***HTTP Basic*** (integrata in **HTTP**).
1) Un client richiede una risorsa che <u>necessita di auth</u> e il server risponde con un *401 Unauthorized*, con campo: “**WWW-Authenticate: \<type\> realm = \<realm\>**”.
2) Il browser client fa quindi visualizzare una pagina per l’<u>immissione di credenziali</u> (questa è detta ***challenge***) e, una volta inserite, vengono inoltrate al server con un messaggio simile all’originale ma con l’aggiunta del campo: “**Authorization: Basic \[*usr e pwd codificati in base64*]**”.
3) Il server <u>riceve</u> i dati, <u>verifica</u> l’auth e <u>invia</u> la pagina richiesta se credenziali valide. Nelle richieste successive il browser invia direttamente l’header *Authorization* senza intervento dell’utente.
