### Network security

**Network security** consists of **policies** and **practices** to <u>prevent</u> (and monitor) <u>unauthorized access to a network and its resources</u>. 

##### Parts

- **Identification**: <u>identifying every user by username</u> / user ID,
- **Authentication**: every <u>user has to prove his identity</u> by digiting a **password**. The password can be based on:
	- *Something the user **knows***: like a string or pin-based password,
	- *Something the user **has***: like identity documents or RFID identification cards,
	- *Something the user **is***: like biometrics, such as fingerprints or eye scan.
- **Authorization**: defining the <u>permissions for each user</u> (what the users can do, like read-only, edit permission...).

###### Secure server

Since any **stop** could <u>reveal personal info</u> when transferred in internet, it's important to use a **secure server** because it <u>encrypts info</u> and make it readable only by the <u>receiver</u>.

##### Website security

<u>Websites that transmit info through encrypted connections</u> are called **secure**, and can be verified in 3 ways:

- With the **padlock symbol** in the browser window frame (when user attempt to login/register, if not on the page itself, might be a fraudulent site),
- The web address starts with "**https://**" (*s* stands for **secure**),
- The <u>address bar</u> / site name turns **green** when digiting the website.

When making <u>payments</u> to individuals, it's better to use <u>secure payment</u> sites like PayPal. Before <u>closing the browser</u>, if sensitive info were inserted, <u>log out</u> from those sites.

### Copyright

> [!important] Copyright
> **Ownership of the rights to use and distribute certain works or creative expression**. It includes both <u>economic</u> and <u>moral</u> rights.

##### Types of rights

###### Economic rights

The rights (of the owner) to **prevent others from exploiting the work** in various ways, <u>without permission</u> or <u>charging a fee for its reproduction</u>.

###### Moral rights

These include:

- The **paternity** right: being identified as the author of the work,
- The **integrity** right: preventing mutilation and distortions.
