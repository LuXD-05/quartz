### Topologies

Based on **location**:

- **Point-to-Point**: normal connection from a pc to another,
- **Star**: topology in which all traffic is directed to each host passing through a central node,
- **Ring**: hosts connected with the next one in form of a ring. Traffico can go in 1 way or in both,
- **Tree**: hierarchical structure in which each node (leaf) derives from a superior node up until the 1st node (root),
- **Bus**: each host is interconnected through a single cable,
- **Mesh**: each host is connected to every other host in the network.

### Typologies

Based on **features**:

- **PAN**: personal (Bluetooth),
- **LAN**: local,
- **MAN**: metropolitan (WiMAX = Wireless MAN),
- **WAN**: wide (national/international = internet. Typical topology = mesh).
